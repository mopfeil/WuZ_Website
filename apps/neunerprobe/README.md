# Neunerprobe

Webapp für das Arbeitsmodell **Wissenschaft und Zauberkunst** (Werkzeugkasten Staunen, PH-Fortbildung Teil 2).
Eine eigenständige `index.html`, kein Build, keine Abhängigkeiten, nichts wird gespeichert. Seit 2026-11-24 auf /werkzeuge/ und /en/tools/ eingetragen; die App selbst trägt wie der Würfel `noindex`.

- **Gedankenleser:** Zahl (≥ 3 Ziffern) minus Quersumme (oder Ziffern umstellen und Differenz), eine Ziffer ≠ 0 einkreisen,
  die übrigen eintippen. Die App nennt die eingekreiste: `(9 − Summe mod 9) mod 9`, 0 → 9. Für alle Zahlen 100–99 999 geprüft.
- **Rechenprobe:** Neunerprobe für ×, +, − mit Tabelle der Neunerreste; Hinweis, dass Zahlendreher unentdeckt bleiben.
- **Warum?:** Begründung (10ⁿ ≡ 1 mod 9).

Angelegt 2026-11-24.
